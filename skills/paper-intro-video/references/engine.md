# The harness

Contents: files · the script · the timeline · stagecraft · the two clocks · captions and HUD ·
sound cues · frame-accurate clips · icons and fonts · looking at frames.

## Files

| file | what it is | you change it |
| --- | --- | --- |
| `js/script.js` | the words and the plan: scenes, narration lines, how they are said | for every film |
| `js/data.js` | every number shown, with its source | for every film |
| `index.html` | one `<section class="scene">` per scene; the HUD; the script tags (order matters) | for every film |
| `css/film.css` | where things sit, scene by scene | for every film |
| `js/scenes.js` | `window.OXBUILD`: data-driven DOM, stations, and every animation | for every film |
| `css/base.css` | stage, tokens, type classes, marks, captions, HUD, windows | to change the look |
| `js/lib/build.js` | script + voice → timing (the two clocks) | rarely |
| `js/lib/stage.js` | stations, camera, kinetic type, marks on cue, captions, chapter bar | rarely |
| `js/lib/engine.js` | the timeline: tweens, calls, scenes | no |
| `js/lib/annotate.js` | hand-drawn marks and arrows (Rough.js) | no |
| `js/lib/player.js` | waits for fonts, builds, drives preview and renderer | no |
| `js/voice.js`, `js/pacing.js` | generated by `tools/narration.py` | never by hand |
| `js/icons.js` | generated by `tools/build_icons.mjs` | never by hand |
| `tools/` | every step of the pipeline; `make.mjs` runs them in order | rarely |
| `package.json` | only says `"type": "commonjs"`, so a package.json further up cannot break `js/*.js` | no |

`build/`, `audio/`, `out/`, `script/` are generated. `voice/<cut>/<name>/` holds the narration clips.

## The script (`js/script.js`)

```js
const FILM = {
  slug: 'myfilm', title: 'Paper title (VENUE 2026)',       // out/myfilm.mp4; the MP4's title tag
  beat: 0.6, chapters: ['Problem', 'Idea', 'Results'],
  posters: [{ name: 'poster_title', scene: 's-title', station: 0, at: -0.9 }],
  scenes: [
    { id: 's-title', title: 'Title card', chapter: null, lead: 0.6, tail: 0.7,
      cues: [ { id: 'name', dur: 7.4, en: 'This is <Name>. …', say: 'This is <how it is said>. …' } ] },
    { id: 's-problem', title: '01 · The problem', chapter: 0, lead: 0.6, tail: 0.9, cues: [ … ] },
  ],
};
```

A scene is a lead-in, cues one after another (`dur` + `gap`, 0.4 s by default), and a tail; its
length is rounded up to the beat. `chapter` is the index of the segment of the bottom bar the
scene belongs to (`null`: none — cold open, title, end). Cue fields: `id`, `dur` (a guess until
the first voice), `gap`, `en`, `say`, `caps: 'each'`, `breath`. `js/lib/build.js` documents them.
More caption languages: `captions: ['en', 'zh']` and a `zh:` text per cue.

## The timeline

Every frame is a pure function of time: `seek(t)` recomputes all animated state from scratch.
That is what lets several browser tabs render frames in any order — and it is why **nothing may
animate by itself**: no CSS transitions or animations, no timers, no state kept between frames.

Inside `window.OXBUILD`, `const S = scene('s-how')` gives the scene's builder. Times are seconds
from the scene start, on the plan's clock.

```js
S.fromTo(target, { opacity: 0, y: 40 }, { opacity: 1, y: 0 }, { at: 1.2, dur: 0.5, ease: 'outCubic', stagger: 0.1 });
S.to(target, { scale: 1.07 }, { at: 3.0, dur: 0.25 });         // from wherever the previous tween left it
S.set(target, { opacity: 0 }, { at: 5 });
S.rise(target, { at, dist: 34, dur: 0.7 });   S.fadeIn(target, { at });   S.fadeOut(target, { at });
S.type(el, 'research https://…', { at, dur: 1.5 });            // typewriter into textContent
S.count(el, 0, 50669, { at, dur: 1.7, sep: true });       // also decimals, prefix, suffix, ease
S.call((p, lt, t) => { /* p: eased progress 0..1; t: film time */ }, { at, dur, ease });
S.sfx('pop', at, { g: 0.5, n: 2, pan: -0.3 });                 // a sound, declared next to its picture
S.$(sel) / S.$$(sel)                                            // inside this scene
```

- `target`: a selector (resolved inside the scene), an element, or a list.
- Properties: `opacity`, `x`, `y`, `z`, `scale`, `scaleX`, `scaleY`, `rotate`, `rotateX`,
  `rotateY`, `blur`; any CSS custom property (`'--k'`) — drive widths, positions and colours
  through `calc(var(--k) * …)` in CSS; `'attr:name'`; any other style property with a number and a
  unit (`width: '320px'`) or a colour (`'#191713'`, `'rgba(…)'`).
- The timeline owns `transform` of what it animates (translate → rotate → scale, in that order).
  Do not give such an element a CSS transform; wrap it.
- Eases (an unknown name throws): `linear`, `in/out/inOut` + `Quad`, `Cubic`, `Quart`; `outQuint`,
  `outExpo`, `inExpo`, `inOutSine`, `outBack` (overshoot), `outBackSoft`, `inBack`, `outElastic`.
- Several tweens on the same element and property play in start order; before the first one the
  element shows that tween's `from`. So an element that enters later needs no "hidden" CSS.
- A callback that watches the clock itself compares `S.now(t)` (plan time) with plan times.

## Stagecraft (`js/lib/stage.js`)

`const ST = window.OXSTAGE()` once; destructure what you need.

```js
// a scene becomes stations (the world the camera looks at) + chrome that stays put
const lay = layout('s-how', [['steps', ['.steps', '#how-ink']], ['rule', ['.rule-card']], ['end', ['.end'], true /* dark */]], ['.sec-head']);
window.OXICON.hydrate(document);                 // icons
$$('[data-split], .sec-title').forEach(splitDeep);   // statements → words
MK.prepare(stage);                               // measure and build every .mk — after layout, before timing

const S = scene('s-how'), c = S.c;               // c.<cue>: when a line starts
chapter(S, lay.chrome.querySelector('.sec-head'), { hold: 0.9 });
camera(S, lay, [ { at: 0, k: 'steps', x: 960, y: 540, s: 1 }, { at: c.follow - 0.5, k: 'steps', x: 960, y: 590, s: 1.04, dur: 1.1 },
                 { at: c.rule - 0.55, k: 'rule' } ]);
words(S, S.$('.rule-h'), c.rule + 0.05, { stagger: 0.11 });
mark(S, '.rule-h .mk', S.w('rule', 'screen.', 1.0) + 0.1);
jot(S, '.how-note', at, { rot: -4 });   pop(S, el, at);   counter(S, node, 12, at, 0.9, (v) => String(Math.round(v)));
draw(S, arrowPaths, at, 0.4);
```

- **Order inside `OXBUILD`:** data-driven DOM → `layout()` for every scene → hydrate icons →
  `splitDeep` → `MK.prepare` → measure free-standing ink (`boxIn`, `MK.arrow`) → `ST.hud()`,
  `ST.captions()` → the scenes → `return tl`. Marks and arrows are measured against the final
  layout and the real fonts; anything added to the DOM afterwards is not.
- **Marks:** `<span class="mk" data-mark="underline|highlight|circle|cross|slash|tick|strike"
  data-color="gold|red|violet|ink" data-pad="12">`. A `.mk` inside a `data-split` statement stays
  one unit.
- **Free ink:** `MK.arrow(svg, [x0, y0], [x1, y1], { color, width, head, bend })`, `MK.line`,
  `MK.circle(svg, cx, cy, d)`, `MK.rect`, `MK.path` return stroke paths for `draw()`. The
  `<svg class="ink">` must be a direct child of the station, so that `boxIn(node, station)`
  coordinates are its coordinates.
- **Camera keys:** `{ at, k: station, x: 960, y: 540, s: 1, dur: 0.9, ease: 'inOutCubic', push }`.
  `x, y` is the point of the station that sits in the middle of the frame.
- **Type classes** (base.css): `.stmt` + `md|lg|xl|xxl|xxxl` (54–168 px serif), `.kicker` (tracked
  label), `.hero-n` (240 px number; `.v` violet, `.r` red, `.sm`, `.xl`), `.hand` (handwritten),
  `.src` (source line), `.sec-head > .sec-title` (chapter headline), `.win`/`.term`/`.sheet`
  (window, terminal, paper sheet), `.dark` (a dark card).

## Two clocks

`js/scenes.js` is written on **the plan**: line windows, and — once a first voice has been laid in
with `--as-plan` — the moment every word is said (`js/pacing.js`). **The film** is what gets
rendered: with a voice (`js/voice.js`) each line lasts as long as it is spoken, plus the room the
plan left, and every scene carries a piecewise-linear map from plan time to film time with a knot
at each word. Everything a scene registers goes through that map (start and end of each tween),
as do sound cues and markers; captions are timed directly from the voice.

What follows:

- `S.w('cue', 'word', fallback, n)` — when a word is said (plan time). `n` picks a later
  occurrence. A word that is not in the line throws: a typo should not silently fall back.
  `S.ws('cue')` — all word times of a line; `S.said('cue', fallback)` — when the line is over.
- Swap the voice and the film follows: its length changes, the frames around each word do not.
  With the voice that made the plan the map is the identity.
- Do not regenerate `js/pacing.js` once scenes are timed, unless the words changed — then lay the
  voice in again with `--as-plan`; `c.<cue>` offsets and `S.w` anchors keep their meaning.
- `{ raw: true }` in a tween's options addresses film time directly (the page turn does).
- `index.html?voice=off` shows the plan as if nobody spoke.

## Captions and the chapter bar

`ST.captions({ dark: [[from, to], …] })` — film-time ranges where the ground is dark.
`ST.hud({ from, until })` — the bar: one segment per entry of `chapters`. Long lines are split
into caption segments of at most about 92 characters at sentence ends, then at a comma; a segment
changes when the voice reaches its first word. The renderer composites captions itself, so the
caption-free and the captioned file come from one capture pass.

## Sound cues

`S.sfx(kind, at, opts)`: `whoosh` (page, camera — added automatically), `pen` (a mark — added by
`mark`/`jot`/`draw` unless `quiet`), `pop` (`n` picks the note), `bell` (a result, a slogan),
`low` (weight), `type` (`n` key presses over `dur`). `g` is the gain, `pan` −1…1.
`S.mark('name', at)` names a moment; scene starts are marked automatically.

## Icons and fonts

`<i data-ph="name" data-w="light|regular|duotone|bold|fill|brand"></i>`; the bundle is built from
`assets/icons/` by `node tools/build_icons.mjs`. Other typefaces: change the Google Fonts link and
the `--serif/--sans/--mono/--hand` tokens, and set `window.OXFACES = ['500 20px "Your Font"', …]`
before `player.js` so the page waits for them (marks are measured against real glyphs).

## Frame-accurate clips and their sound

1. Put owned or cleared source footage outside `media/`. Fill `CLIPS` and optional `SOUNDS` in
   `tools/prep_media.py`; it needs ffmpeg only for this preparation step. Crop and downscale before
   extracting JPEGs. `python tools/prep_media.py` creates `media/manifest.js` and numbered frames.
   Inspect an existing `media/` before `--replace`; replacement keeps it as `media.backup-*`.
2. Load `media/manifest.js` before `js/media.js` in `index.html` (uncomment the provided tag).
3. Use an `<img>` and a scene cue:
   ```js
   OXMEDIA.play(S, img, 'demo', { at: c.result, from: 1.5 });
   S.mark('demoSound', c.result); // only when this clip's sound is wanted
   ```
   `from` is seconds into the prepared clip. It holds its first selected frame before the cue and its
   final frame after the end. `window.__seek(t)` returns a promise; every capture must await it.
4. For sound, set `SOUND_MARKS` in `tools/clip_audio.py` to the same clip and `from`, export the cue
   sheet, then run the script. It writes `audio/full/clips.wav` and `build/full/duck.json`.
   Clip sound trims at the playback mark and film boundaries; overlapping clips mix, and clipping fails
   loudly. Keep source picture and sound on the same time origin. This is not automatic in `make.mjs`:
   ```bash
   node tools/export_sfx.mjs
   python tools/clip_audio.py
   node tools/render.mjs --audio audio/full/soundtrack.wav,-1 --audio build/full/narration.wav,0 \
     --audio audio/full/clips.wav,-1 --duck build/full/duck.json,-8 --lufs -16
   python tools/check_audio.py out/<slug>.mp4 --strict
   ```

An absent manifest entry becomes a labelled plate and console warning, useful for examples without
redistributable footage. A present entry whose JPEG cannot decode stops capture. Placeholder renders
are previews, never evidence of model output or a finished deliverable.
